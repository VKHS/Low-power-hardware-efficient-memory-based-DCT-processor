Low-power hardware-efficient memory-based DCT processor

Claims and how each one is established

Every number on this page is computed by the repository's own code, or quoted from the paper and marked as quoted. The basis column says which.

Re-run in this browser

These checks run when the page opens, with code written for this page (model.js, sched.js, sha256.js) and the vector files embedded in it. They share no code with the Python models.

Accuracy

All errors are measured against double-precision references: SQNR for the 1-D transform, PSNR for the 8×8 transform on images.

Dynamic range

Safe scaling and headroom bits are chosen so that no flow-graph node and no CORDIC register leaves its word.

Schedule and memory

One butterfly unit pair and one CORDIC unit process a block every 8 cycles. The schedule file is the single source of the control words in the RTL and the HLS kernels.
