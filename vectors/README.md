# Golden vectors

Generated by `python -m dct8 vectors` (run from `python/`) and used by the RTL, HLS and
MATLAB test benches. `manifest.json` lists the parameters, counts and the expected
first-output cycle of every set.

| file | content |
|---|---|
| `<set>_stim.hex` | one line per clock: `{in_valid, in_data}` (B_IN + 1 bits), including invalid gap blocks |
| `<set>_expect.hex` | one line per valid output word, in output order (1-D: Y0..Y7 per block; 2-D: column by column) |
| `<set>_in.txt` | one valid block per line (8 or 64 decimal inputs, 2-D blocks row-major) |
| `<set>_out.txt` | the matching outputs (1-D: Y0..Y7; 2-D: X[u][v] row-major) |
| `schedule.json` | the modulo schedule and register allocation |
